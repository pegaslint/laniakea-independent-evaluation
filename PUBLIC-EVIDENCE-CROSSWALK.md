# Public Evidence Crosswalk

The canonical report was assembled from a larger private validator workspace. This minimized public release does not separately distribute every modular source file, phase report, acquisition record, transport record, or internal control file. An evidence-note path therefore does not always name a standalone public file. This crosswalk identifies where its evaluated content can be inspected publicly.

A public representation is not necessarily byte-for-byte identical to a withheld private source file. Omission does not by itself invalidate an evidence-note reference or establish its underlying claim. Publication minimization avoids unnecessary session, contributor, transport, local-workspace, and internal-process metadata. Public representation of a conclusion is distinct from public distribution of its underlying artifact.

Read the [canonical report](synthesis/publication/full-report-final.md) for the controlling explanation, the [public master matrix](synthesis/master-evidence-matrix.md) for claim rows and dispositions, and the [manifest](PUBLIC-MANIFEST.md) for the exact public allowlist. This is a navigation aid, not new evidence or a new evaluation.

## Public-distribution statuses

| Status | Meaning |
|---|---|
| DIRECTLY DISTRIBUTED | The referenced artifact is present at the stated public path. Where the manifest identifies a public derivative, presence does not assert byte identity to a private version. |
| REPRESENTED IN PUBLIC REPORT | The separate private/source component is not distributed, but its evaluated substantive content appears in the canonical report and/or public matrix. |
| WITHHELD BY PUBLICATION MINIMIZATION | The retained private artifact is not distributed because it is unnecessary for minimum traceability, redundant, raw transport/process material, or contains unnecessary metadata. |
| EXCLUDED / NOT ACCEPTED EVIDENCE | Material explicitly excluded from the accepted evaluation evidence population. |
